SECTION 4 OF 6

Installing the Hard Boys Pack

Blockhead runs a custom build of Expert Survival. You need the same mods to join. Four steps.

  1. Get the pack zip from #minecraft-server in the Discord. Current build: Hard Boys Pack v1.0.
  2. Import it in the CurseForge app: Minecraft → Create Custom Profile → Import → pick the zip. It installs NeoForge 26.2.0.75 and every mod.
  3. Give it RAM. 6 GB or more in CurseForge settings makes the first load much happier.
  4. Add the server as superfucked.xyz in Multiplayer and join. Accept the resource pack when prompted.

Playing from inside the same house as the server? Use 192.168.1.237:25565. The router won't loop the public address back.
