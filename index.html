▸ Modded Minecraft

The Hard Boys Pack

Blockhead runs a custom build of Expert Survival. You need the same mods to join — here's the whole setup.

  1. Get the pack zip from the #minecraft-server channel in our Discord (current build: Hard Boys Pack v1.0).
  2. Import it in the CurseForge app: Minecraft → Create Custom Profile → Import → pick the zip. It installs NeoForge 26.2.0.75 and every mod for you.
  3. Give it RAM — 6 GB or more in CurseForge settings makes the first load much happier.
  4. Add the server as superfucked.xyz in Multiplayer and join. Accept the resource pack when prompted for glowing ores.

Playing from inside the same house as the server? Use 192.168.1.237:25565 — the router won't loop the public address back.
